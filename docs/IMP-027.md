# IMP-027 — Automação de Mineração, Importação e Padronização de Imagens de Afiliados Mercado Livre

## 1. Contexto & Objetivo

O programa de afiliados do Mercado Livre para o **Estratégia Nerd** demandava um fluxo manual lento para cadastrar produtos no painel (`/admin/links`), inconsistência visual entre as capas existentes (mistura de proporções 4:5 verticais e 1:1, arquivos PNG pesados de até 2.2 MB) e um bug no monitoramento de links (`performHttpCheck`) que marcava links encurtados `meli.la` como `quebrado` devido à rejeição de requisições `HEAD` (HTTP 405).

O objetivo do **IMP-027** é:
1. **Motor de Extração e Resolução de Afiliados (`MercadoLivreExtractorService.php`):** Extrair dados canônicos de qualquer anúncio do Mercado Livre ou link curto `meli.la` (título limpo, preço, notas 4.8+, selos oficiais de Mais Vendido/Loja Oficial/Full, foto em alta resolução do CDN).
2. **Motor de Padronização Visual das Capas:** Fixar a identidade visual dos produtos no padrão **Dark Tech / Cyberpunk Hero Shot**, proporção estritamente 1:1 quadrada (1080×1080 px), formato `.webp` ultraleve (85% qualidade) com peso médio entre 60 KB e 140 KB (redução de mais de 93% em relação aos PNGs antigos).
3. **Comando CLI de Importação (`scripts/en-ml-import.php`):** Importar produtos diretamente pelo terminal com extração de metadados, processamento de imagem, geração de slug amigável e cadastro no MySQL.
4. **Comando CLI de Mineração para IAs e Agentes (`scripts/en-ml-miner.php`):** Ferramenta de mineração inteligente com corte rigoroso de nota ($\ge 4.8$), entrega estruturada em JSON para agentes e IAs, e opção de importação automática (`--auto-import`).
5. **Correção do Monitoramento HTTP:** Adicionar fallback para requisições `GET` no `LinksService::performHttpCheck()` para links `meli.la` e que retornem HTTP 405 a requisições `HEAD`.
6. **Otimização do Catálogo Existente (`scripts/en-links-standardize-images.php`):** Converter todas as capas de produtos do portal para o padrão 1080×1080 WebP, economizando mais de 17 MB de banda.
7. **Homologação com Produto Real:** Cadastro do **Hub USB 3.0 Ugreen 4 Portas Ultra Slim (Cabo 1 Metro)** com nota 4.9/5.0 e capa oficial padronizada.

## 2. Componentes e Serviços Implementados

### 2.1. MercadoLivreExtractorService (`app/Services/Affiliate/MercadoLivreExtractorService.php`)
- **Resolução de Links:** Segue redirects 301/302 de `meli.la` preservando os parâmetros de rastreamento de afiliados (`tag=estrategianerd` ou `matt_tool`).
- **Extração Híbrida:** Prioridade para `schema.org/Product` via JSON-LD e fallbacks robustos para OpenGraph, meta tags e DOM do Mercado Livre.
- **Gerador de Prompt Mestre:** Monta o prompt padronizado para IAs geradoras de imagem (estúdio dark tech, iluminação neon ciano/âmbar, foco macro 75% no produto).
- **Pipeline Gráfico GD (`standardizeImage`):**
  - Recorte centralizado para proporção 1:1;
  - Redimensionamento suave para 1080 × 1080 px;
  - Conversão para WebP 85% de qualidade;
  - Preservação de canal alpha para transparências.

### 2.2. Importador de Produtos (`scripts/en-ml-import.php`)
```bash
php scripts/en-ml-import.php --url="https://..." --subgrupo="Setup Gamer" --affiliate-tag="estrategianerd"
```
- Parâmetros suportados: `--url`, `--affiliate-url`, `--affiliate-tag`, `--subgrupo`, `--title`, `--image`, `--promocao`, `--destaque`, `--dry-run`.
- Gera slug único no banco através de `LinkRepository::nextAvailableSlug()`.
- Cadastra com status `ativo` e rota `/link/{slug}` pronta para redirecionamento e métricas de clique.

### 2.3. Minerador para IAs e Agentes (`scripts/en-ml-miner.php`)
```bash
# Saida formatada em JSON para consumo direto por LLMs / IAs:
php scripts/en-ml-miner.php --urls="https://meli.la/2D5Y6ir,https://..." --min-rating=4.8 --json

# Mineracao e cadastro automatico:
php scripts/en-ml-miner.php --urls="..." --auto-import --subgrupo="Setup Gamer"
```
- Suporte a `--query`, `--urls` (lista separada por vírgula) e `--file` (arquivo de texto).
- Aplica corte rigoroso de nota ($\ge 4.8$) e selos de Mais Vendido / MercadoLíder Platinum.

### 2.4. Correção em LinksService (`app/Services/Admin/LinksService.php`)
- No método `performHttpCheck()`, requisições com código 405 ou 403 em domínios de afiliados agora disparam fallback automático via `GET` com headers de navegador e `CURLOPT_RANGE: 0-2048`.
- Todos os 5 links anteriormente marcados como `quebrado` foram validados com status `ativo` e HTTP 200.

### 2.5. Otimizador de Capas (`scripts/en-links-standardize-images.php`)
- Varreu os 14 itens do catálogo original convertendo arquivos PNG pesados (de até 2.2 MB) para WebP 1080×1080 (média de 50 KB a 150 KB).
- **Economia total gerada:** **17.13 MB**.

## 5. Coleta dos 3 PCs Gamer (04/10/2026)

Três montagens de PC cadastradas na Central Nerd, cada uma como grupo próprio (`subgrupo_publico`): **PC Gamer Inicial**, **PC Gamer Intermediário** e **PC Gamer Topo**. Só no banco local; stage e produção dependem do content-sync.

### 5.1. Fluxo usado
1. Peças escolhidas por busca na web (anúncios do Mercado Livre).
2. Links `meli.la` gerados pelo usuário no painel de afiliados.
3. Conferência de cada link com `en-ml-miner.php --urls="..." --json` (somente leitura).
4. Cadastro (#18–#37 importados por um script avulso, fora do repositório) e correção dos campos.

### 5.2. Limitações encontradas
- O Mercado Livre redireciona páginas de produto e de busca para `/gz/account-verification` (login) quando acessadas por script. A API pública responde 401/403 sem token. Hoje o extrator só lê links `meli.la`, que abrem a página social do afiliado.
- Pela página do afiliado, o título e a foto vêm certos, mas **preço, selos e nota não são confiáveis**: preços trocados ou zerados, "Mais Vendido" e "Loja Oficial" em todos os produtos (o texto existe na página, não no produto), nota e descrição vazias. Por isso os produtos dos PCs ficam **sem selo** e com descrição padrão.
- Falhas do extrator e do minerador registradas no Forge (#705).

### 5.3. Campos padronizados
- `cta_curto` = peça ("Processador", "Placa-mãe", "Memória", "SSD", "Placa de vídeo", "Cooler", "Fonte", "Gabinete"). Quando há duas placas de vídeo: "(opção AMD)" / "(opção NVIDIA)" no Intermediário e "(alternativa)" no Topo.
- `selo` vazio; `texto_botao` = "Ver no Mercado Livre"; `descricao` = "Peça do PC Gamer <nível> montado pelo Estratégia Nerd. Confira preço e avaliações no Mercado Livre."
- `posicao`: 210–270 (Inicial), 310–390 (Intermediário), 410–490 (Topo), depois do catálogo existente (10–150) e na ordem processador → placa-mãe → memória → SSD → vídeo → cooler → fonte → gabinete.
- Slugs mantidos como na importação (preservam `/link/{slug}` e a pasta da capa).
