# IMP-029 — Importador de Afiliados por Ficha JSON (Shopee, AliExpress e Mercado Livre)

## 1. Contexto & Objetivo

O importador do IMP-027 (`scripts/en-ml-import.php`) lê a página do produto sozinho e grava textos fixos do Mercado Livre. Isso não serve para a **Shopee**:

- A Shopee entrega uma página de verificação de tráfego para acessos por script (e também no navegador sem login); a API pública (`/api/v4/item/get`) responde 403.
- No **Chrome logado do usuário** a página do produto abre normalmente e traz JSON-LD `Product` completo: nome, imagem, preço, estoque, nota, número de avaliações, marca e loja.
- A imagem do produto (`down-br.img.susercontent.com`) é baixada por script sem bloqueio.
- A API oficial do Shopee Afiliados (GraphQL `open-api.affiliate.shopee.com.br/graphql`, com `productOfferV2` e `generateShortLink`) exige AppID e Secret; o acesso foi pedido no painel ("Abrir API") e ainda não foi liberado (Forge #710).

O objetivo do IMP-029 foi criar um importador que **não lê a loja**: recebe fichas já conferidas (coleta assistida hoje, API no futuro) e cadastra com validação completa.

---

## 2. Fluxo de coleta assistida (Shopee)

1. Abrir o anúncio no Chrome logado e ler o JSON-LD `Product` (nome, imagem, nota, loja).
2. Gerar o link de afiliado no painel Shopee Afiliados → **Oferta → Link personalizado**: colar a URL do anúncio, preencher **Sub_id 1 = `centralnerd`** (identifica nos relatórios os cliques vindos do site) e clicar em **Obter link** → `https://s.shopee.com.br/XXXX`.
3. Montar a ficha JSON (seção 3) e rodar `--dry-run`.
4. Rodar sem `--dry-run` para cadastrar.

---

## 3. Formato da ficha

```json
{
  "versao": 1,
  "produtos": [
    {
      "loja": "shopee",
      "titulo": "Mouse Gamer Marvo M292 RGB 8000DPI 7 Botões Branco",
      "url": "https://s.shopee.com.br/30oVtaAYFL",
      "imagem": "https://down-br.img.susercontent.com/file/...",
      "subgrupo": "Setup Gamer",
      "cta_curto": "8000 DPI e RGB",
      "selo": "⭐ 4.9 / 5.0",
      "descricao": "...",
      "posicao": 160,
      "status": "ativo",
      "origem": "https://shopee.com.br/...-i.627750190.21998280953"
    }
  ]
}
```

- Obrigatórios: `loja` (`shopee` | `aliexpress` | `mercadolivre`), `titulo`, `url`, `imagem`, `subgrupo`, `posicao`, `status` (`ativo` | `oculto`).
- Opcionais: `cta_curto`, `selo`, `descricao`, `origem` (só registro; não vai para o banco).
- Fixos no cadastro: `tipo = produto`, `secao_publica = produtos`; `texto_botao` e `desconto_contexto` por loja ("Ver na Shopee" / "na Shopee", "Ver no Mercado Livre" / "no Mercado Livre"); `observacao_status = "Importado via ficha JSON (<loja>)"`.

---

## 4. Uso

```bash
C:\xampp\php\php.exe scripts/en-affiliate-import.php --file="fichas.json" --dry-run
C:\xampp\php\php.exe scripts/en-affiliate-import.php --file="fichas.json"
```

- `--dry-run`: só valida e mostra a prévia. **Não grava nada** (nem banco, nem capa).
- `--allow-duplicate`: permite link de afiliado já cadastrado ou repetido no lote (ex.: a mesma peça em dois grupos).

### 4.1. Fase 1 — validação de todo o lote (nada é gravado se algum item falhar)
- Limites de campo: título 150, grupo 80, texto curto 120, selo 60, descrição 255.
- Link de afiliado `https` no host da loja: Shopee `s.shopee.com.br` ou `shope.ee`; AliExpress `s.click.aliexpress.com`; Mercado Livre `meli.la`.
- O link curto é resolvido: reprovado se cair em página de erro (`shope.ee/error_page`), fora do domínio da loja ou, na AliExpress, fora de uma página de produto (`/item/<id>.html`).
- Imagem `https` em `susercontent.com`, `mlstatic.com`, `aliexpress-media.com` ou `alicdn.com` (por sufixo).
- Link já cadastrado no banco ou repetido no lote: reprovado, salvo `--allow-duplicate`.
- Slugs únicos no banco e dentro do lote.

### 4.2. Fase 2 — cadastro, por item
1. Capa padronizada (WebP 1080×1080, 85%) em `uploads/links/<slug>/capa.webp`.
2. `INSERT` em `links`. Se o `INSERT` falhar, a capa recém-criada é apagada.
3. Relatório por item; código de saída ≠ 0 se algum item falhar.

---

## 5. Monitor de links (`LinksService::performHttpCheck`)

Link curto inválido da Shopee redireciona para `https://shope.ee/error_page`, que responde **200** — antes passava como "ativo". Agora, se o destino final for a página de erro da Shopee (`shope.ee` ou `shopee.com.br` com `error_page`), a checagem falha e o link vai para **Revisar** (`quebrado`) com a observação "Link da Shopee invalido (pagina de erro)".

Na AliExpress, link `s.click.aliexpress.com` inválido cai na página inicial de ofertas (`best.aliexpress.com`, também 200). Se o destino final de um `s.click.aliexpress.com` for `best.aliexpress.com`, o link vai para **Revisar** com "Link da AliExpress invalido (caiu na pagina inicial)". Premissa: link de afiliado válido da AliExpress leva a um produto (os 5 do catálogo levam a `pt.aliexpress.com/item/<id>.html`); um link de campanha que caia na página inicial também seria marcado.

Os demais links (inclusive `meli.la`) seguem a regra anterior.

## 7. Limitações e dívida técnica

- A coleta depende do Chrome logado do usuário e do JSON-LD da Shopee, que pode mudar sem aviso.
- `standardizeImage` é reaproveitado de `MercadoLivreExtractorService` (o método é genérico). Extrair para uma classe neutra quando vier o serviço da API da Shopee.
- Produto removido na Shopee continua respondendo 200 ("O produto não existe" é desenhado pelo JavaScript); o monitor só detecta link curto inválido.
- A Central Nerd não exibe `texto_botao` nem `cta_curto` (só a prévia da home usa); os campos ficam gravados.
- Preço não é gravado (a tabela `links` não tem campo de preço).
