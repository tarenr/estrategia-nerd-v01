Tipo: Correcao
Nome: Endurecimento de autenticacao e CSRF

Objetivo:
Corrigir o fluxo de autenticacao para bloquear CSRF invalido de forma imediata, endurecer login/logout, eliminar fallback inseguro persistente de senha plaintext e adicionar smoke tests de auth.

Contexto:
O projeto tinha riscos reais no fluxo de autenticacao. O retorno de validacao de CSRF no login/logout nao encerrava o fluxo com seguranca e havia compatibilidade insegura com senha em texto puro. A entrega criou uma ponte de migracao controlada para password_hash e adicionou smoke tests para validar os cenarios criticos.
