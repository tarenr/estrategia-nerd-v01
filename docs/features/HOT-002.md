ID: HOT-002
Tipo: Hotfix
Nome: Corrige cache do JS do dashboard admin

Objetivo:
Corrigir o versionamento dos assets do admin para garantir que o navegador carregue o admin-dashboard.js atualizado em producao.

Contexto:
Depois da promocao do asset public/assets/js/admin-dashboard.js da stage para producao, o dashboard ainda podia continuar usando a versao antiga em cache porque o layout calculava o filemtime a partir de app/public, e nao da raiz real do projeto. Com isso o parametro de versao ficava preso em v=1.

Arquivos alterados:
- app/Views/layouts/admin.php

Impacto em producao: baixo
Afeta rotas criticas: nao

Mudanca de schema: nao
Mudanca de dados: nao

Dependencias:
- Asset public/assets/js/admin-dashboard.js ja promovido da stage para producao.

Risco:
Baixo. A alteracao afeta somente o cache buster de CSS/JS do layout admin.

Validacao:
- php -l app/Views/layouts/admin.php
- git diff --check
- validar que o dashboard passa a servir admin-dashboard.js com versao baseada no arquivo real.

Origem validada: estrategia-nerd-stage
Paridade local -> stage: validada
Paridade stage -> pacote: nao aplicavel

Validado local: sim
Validado stage: sim
