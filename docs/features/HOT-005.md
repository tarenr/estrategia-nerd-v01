# HOT-005 - Protege dashboard contra falha de banco remoto

## Objetivo

Evitar que o dashboard admin gere fatal error quando o banco do ambiente alvo remoto estiver inacessivel, com credencial recusada ou sem permissao para o banco configurado.

## Contexto

Ao selecionar Stage ou Producao como ambiente alvo, o dashboard tentava abrir a conexao PDO remota antes de montar qualquer payload. Quando o MySQL recusava a conexao, a excecao derrubava a pagina inteira.

## Arquivos alterados

- `app/Controllers/Admin/DashboardController.php`
- `app/Views/admin/dashboard.php`
- `docs/features/HOT-005.md`

## Impacto em producao

Baixo. A mudanca afeta apenas o comportamento do dashboard admin quando o banco do ambiente alvo falha. Em conexoes saudaveis, o fluxo segue usando os mesmos repositories e o mesmo `DashboardService`.
