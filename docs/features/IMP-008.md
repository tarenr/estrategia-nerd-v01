ID: IMP-008
Tipo: Melhoria
Nome: Backup completo com arquivos do sistema e Dropbox

Objetivo:
Transformar a rotina de Backup e Restore em backup completo de sistema, incluindo banco, uploads e arquivos do sistema, e garantir que o envio para Dropbox carregue o pacote completo.

Contexto:
A rotina anterior era chamada de backup completo, mas gerava apenas database.sql e uploads.zip. Isso deixava os arquivos do sistema fora do pacote principal e criava confusao entre backup completo, backup tecnico e pacote de conteudo. A documentacao tambem descrevia o modelo antigo.
