ID: IMP-017
Tipo: Melhoria
Nome: Animacao do hero principal com Anime.js

Objetivo:
Melhorar a percepcao visual do hero principal da home com animacoes de entrada e microinteracoes sem migrar a tela para React ou alterar a estrutura principal da pagina.

Contexto:
Foi avaliado o uso de Bklit/React para o dashboard, mas a direcao escolhida foi manter a stack PHP tradicional e usar bibliotecas pontuais quando agregarem valor. Para o hero publico, Anime.js foi adotado como camada leve de animacao sobre os elementos existentes.

Arquivos alterados:
- `app/Views/site/home.php`
- `app/Views/components/site/home/header-hero-preview.php`
- `public/assets/js/site-hero-preview.js`
- `docs/features/IMP-017.md`

Mudanca realizada:
- Adicionado Anime.js via CDN na home publica.
- Inseridos atributos `data-hero-animate` nos elementos principais do hero.
- Criada animacao progressiva de entrada para eyebrow, titulo, subtitulo, texto, pontos de apoio, botoes e link recente.
- Adicionadas microinteracoes nos botoes do hero.
- Preservado o canvas visual existente do hero.
- Respeitado `prefers-reduced-motion`, deixando os elementos visiveis sem animacao quando movimento reduzido estiver ativo.
- Implementado fallback para manter a home funcional caso Anime.js nao carregue.

Banco de dados:
- Mudanca de schema: nao
- Mudanca de dados: nao
- Script necessario: nao

Dependencias:
- CDN `https://cdn.jsdelivr.net/npm/animejs@4.5.0/dist/bundles/anime.umd.min.js`
- JS existente `public/assets/js/site-hero-preview.js`

Impacto em producao:
Baixo. A mudanca afeta somente a home publica e adiciona uma dependencia visual por CDN. O conteudo permanece renderizado server-side e funcional sem a biblioteca.

Afeta rotas criticas:
Sim. Afeta a home publica `/`.

Risco:
Baixo. O principal risco e visual, caso o CDN esteja indisponivel ou a animacao nao seja percebida em algum navegador. O fallback evita ocultar conteudo.

Validacao minima:
- `php -l app/Views/site/home.php`
- `php -l app/Views/components/site/home/header-hero-preview.php`
- `node --check public/assets/js/site-hero-preview.js`
- Acessar a home publica.
- Confirmar animacao de entrada no hero.
- Confirmar que o hero permanece legivel com movimento reduzido.
- Confirmar que o canvas do hero continua renderizando.

Status:
- Local: implementado

Observacoes:
