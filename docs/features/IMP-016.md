ID: IMP-016
Tipo: Melhoria
Nome: Dashboard admin com graficos Chart.js e filtro sem reload

Objetivo:
Melhorar a leitura operacional do dashboard admin mantendo os cards existentes e acrescentando graficos para tendencia, comparacao e distribuicao.

Contexto:
O dashboard admin ja concentrava indicadores de posts, views, inscricoes, comentarios, links, destaques editoriais, categorias e atividade por periodo. Antes desta melhoria, a area de Atividade usava SVG manual na view PHP e o filtro de datas recarregava a pagina inteira.

Arquivos alterados:
- `app/Controllers/Admin/DashboardController.php`
- `app/Repositories/LinkClickRepository.php`
- `app/Services/Admin/DashboardService.php`
- `app/Views/admin/dashboard.php`
- `app/Views/layouts/admin.php`
- `public/assets/css/admin.css`
- `public/assets/js/admin-dashboard.js`
- `docs/features/IMP-016.md`

Mudanca realizada:
- Adicionado Chart.js somente no layout do dashboard admin.
- Substituido o SVG manual de Atividade por grafico misto com views, media movel, posts novos e inscricoes.
- Adicionados graficos auxiliares sem remover cards:
  - Hoje: barras horizontais com posts, views, inscritos e comentarios.
  - Links e Central Nerd: linha temporal de cliques totais e cliques unicos por dia.
  - Secoes mais clicadas: grafico doughnut de distribuicao.
  - Destaques editoriais: barras horizontais para mais visto, mais curtido e mais comentado.
  - Categorias: top categorias por views com posts como comparativo auxiliar.
- Criado retorno `html` no endpoint `/admin/api/dashboard` para atualizar o miolo do dashboard via AJAX.
- O filtro de datas passou a atualizar somente o dashboard, sem recarregar a pagina inteira.
- Os graficos antigos sao destruidos e recriados apos cada atualizacao AJAX.
- Containers dos graficos receberam altura controlada para evitar canvas crescendo alem do painel.

Banco de dados:
- Mudanca de schema: nao
- Mudanca de dados: nao
- Script necessario: nao

Dependencias:
- CDN `https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js`
- Endpoint autenticado `/admin/api/dashboard`
- Tabela `link_clicks` ja gerenciada por `LinkClickRepository`

Impacto em producao:
Baixo a medio. A mudanca afeta a rota autenticada `/admin` e adiciona dependencia de CDN para renderizacao dos graficos. Os dados principais continuam visiveis pelos cards e listas caso o Chart.js nao carregue.

Afeta rotas criticas:
Sim. Afeta `/admin`.

Risco:
Baixo a medio. O maior risco e visual ou de disponibilidade do CDN. O dashboard continua renderizando os cards e o HTML server-side. O filtro AJAX possui fallback para submit normal se a chamada falhar.
