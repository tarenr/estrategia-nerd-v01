ID: IMP-013
Tipo: Melhoria
Nome: URLs amigaveis nas secoes da Central Operacional V2

Objetivo:
Padronizar as abas internas da Central Operacional V2 para usarem segmentos de URL em vez de parametros de secao na query string.

Contexto:
O SEO Tecnico passou a usar /seo-tecnico/resumo e /seo-tecnico/inspecao. A mesma convencao foi aplicada aos demais modulos com abas internas para deixar a navegacao local mais consistente e legivel.

Arquivos alterados:
- config/routes.php
- app/Controllers/Admin/OperationsV2Controller.php
- app/Views/admin/operations-v2/index.php
- app/Views/admin/operations-v2/panel.php
- app/Views/site/backup-tools.php
- app/Views/site/partials/backup-tools-content.php
- app/Views/admin/operations-v2/backup-editorial.php
- app/Views/admin/operations-v2/partials/backup-editorial-content.php
- app/Views/admin/operations-v2/backup-nuvem.php

URLs novas:
- /admin/central-operacional-v2/backup-sistemico/resumo
- /admin/central-operacional-v2/backup-sistemico/acoes
- /admin/central-operacional-v2/backup-sistemico/restore
- /admin/central-operacional-v2/backup-sistemico/historico
- /admin/central-operacional-v2/backup-editorial/resumo
- /admin/central-operacional-v2/backup-editorial/acoes
- /admin/central-operacional-v2/backup-editorial/restore
- /admin/central-operacional-v2/backup-editorial/historico
- /admin/central-operacional-v2/backup-em-nuvem/resumo
- /admin/central-operacional-v2/backup-em-nuvem/historico
- /admin/central-operacional-v2/seo-tecnico/resumo
- /admin/central-operacional-v2/seo-tecnico/inspecao

Compatibilidade:
As URLs antigas com query string continuam aceitas para nao quebrar links existentes. O antigo /admin/central-operacional-v2?painel=... redireciona para a pagina amigavel do modulo correspondente.

Home da Central:
A entrada /admin/central-operacional-v2 deixou de trocar paineis por query string. Ela funciona como hub fixo com cards diretos para os modulos da Central.

Banco de dados:
- Mudanca de schema: nao
- Mudanca de dados: nao
- Script necessario: nao

Impacto em producao:
Nao aplicavel no fluxo atual. A Central Operacional V2 permanece como area tecnica local, conforme a separacao documentada entre admin tecnico local e administracao editorial reduzida em stage/producao.

Risco:
Baixo a medio. O maior risco e link interno de aba nao marcar estado ativo corretamente; validacao local cobriu reconhecimento das novas rotas.

Validacao:
- php -l nos controllers/views alterados.
- Rotas novas retornam 302 para login quando sem sessao, confirmando reconhecimento pelo roteador.
- Home da Central nao gera mais links com ?painel=.
- git diff --check sem erro bloqueante.

Status:
- Local: validado
- Stage: nao aplicavel enquanto a Central Operacional V2 permanecer restrita ao ambiente tecnico local
- Producao: nao aplicavel enquanto a Central Operacional V2 permanecer restrita ao ambiente tecnico local
