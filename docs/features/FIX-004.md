ID: FIX-004
Tipo: Correcao
Nome: Sessao local em pasta controlada do projeto

Objetivo:
Evitar instabilidade local de sessao causada por permissao do `C:\xampp\tmp`, direcionando sessoes do ambiente local/desenvolvimento para `storage/sessions`.

Contexto:
O PHP local estava configurado com `session.save_path="C:\xampp\tmp"`. A pasta existe, mas depende das permissoes globais do XAMPP e pode gerar `Permission denied` quando Apache/PHP rodam em contexto diferente ou quando arquivos de sessao ficam presos por processo anterior.

Arquivos alterados:
- bootstrap.php
- config/app.php
- docs/features/FIX-004.md

Comportamento:
- `SESSION_SAVE_PATH` pode definir explicitamente o caminho de sessao.
- Quando `SESSION_SAVE_PATH` nao estiver definido e `APP_ENV` for `local`, `development` ou `dev`, o sistema usa `storage/sessions`.
- Stage e producao nao mudam automaticamente de caminho.
- Se a pasta configurada nao existir, o bootstrap tenta cria-la.
- Se a pasta nao for gravavel, o sistema registra erro e preserva o comportamento padrao do PHP.

Banco de dados:
- Mudanca de schema: nao
- Mudanca de dados: nao
- Script necessario: nao

Impacto em producao:
Nao aplicavel no fluxo atual. A mudanca automatica e restrita a ambiente local/desenvolvimento, salvo configuracao explicita por `SESSION_SAVE_PATH`.

Risco:
Baixo. A mudanca ocorre antes de `session_start()` e preserva fallback para o caminho padrao do PHP quando o diretorio configurado nao estiver disponivel.

Validacao:
- `php -l` nos arquivos PHP alterados.
- Confirmar que `session_save_path()` aponta para `storage/sessions` em ambiente local.
- `git diff --check` sem erros.
