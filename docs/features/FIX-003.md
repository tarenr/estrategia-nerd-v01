ID: FIX-003
Tipo: Correcao
Nome: URLs amigaveis no ambiente local

Objetivo:
Remover /public das URLs geradas no ambiente local via XAMPP, mantendo o front controller em public/index.php.

Contexto:
O APP_URL local apontava para http://localhost/estrategia-nerd/public. Com isso, links internos do admin eram gerados com /public na barra, deixando a navegacao local diferente do padrao amigavel usado nas rotas do projeto.

Arquivos alterados:
- .htaccess
- .env local

Banco de dados:
- Mudanca de schema: nao
- Mudanca de dados: nao
- Script necessario: nao

Dependencias:
- Apache com AllowOverride ativo no XAMPP
- public/.htaccess existente

Impacto em producao:
Nenhum esperado. A mudanca do .env foi local e o .htaccess da raiz serve para desenvolvimento em subpasta no XAMPP.

Risco:
Baixo. A regra preserva compatibilidade com URLs antigas em /public e bloqueia acesso direto a pastas tecnicas pela raiz local.

Validacao:
- /estrategia-nerd/admin/central-operacional-v2/seo-tecnico redireciona para /estrategia-nerd/login quando sem sessao.
- /estrategia-nerd/assets/css/admin.css retorna 200.
- /estrategia-nerd/app/Support/Helpers.php retorna 403.
- /estrategia-nerd/public/admin/central-operacional-v2/seo-tecnico continua resolvendo por compatibilidade.

Status:
- Local: validado
- Stage: nao aplicavel
- Producao: nao aplicavel
