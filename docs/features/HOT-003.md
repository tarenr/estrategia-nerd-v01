ID: HOT-003
Tipo: Hotfix
Nome: Corrige leitura dos filtros de data no dashboard

Objetivo:
Garantir que os indicadores de periodo do dashboard admin acompanhem o filtro de data e nao exibam totais historicos como se fossem valores filtrados.

Contexto:
Em producao, o filtro aplicava start/end na URL e o grafico mudava, mas alguns numeros permaneciam iguais. A revisao mostrou que parte dos cards do topo usava acumulados globais enquanto a secao Atividade usava chart.current. Tambem havia um fallback de views que podia trocar o valor filtrado pelo total geral quando faltavam dados recentes em estatisticas.
Depois da correcao inicial, foi identificado que o seletor Local ainda montava links, capas e URLs publicas com dominio de producao quando a base local continha configuracoes.site_url apontando para producao.

Arquivos alterados:
- app/Controllers/Admin/DashboardController.php
- app/Services/Admin/DashboardService.php
- app/Views/admin/dashboard.php
- public/assets/js/admin-dashboard.js
- public/assets/css/admin.css
