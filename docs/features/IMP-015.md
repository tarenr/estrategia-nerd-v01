ID: IMP-015
Tipo: Melhoria
Nome: Estruturas de posts na Base de Conhecimento do admin

Objetivo:
Adicionar no menu tecnico do admin uma pagina no padrao da Base de Conhecimento para consultar estruturas oficiais de conteudo do blog.

Contexto:
O projeto ja possuia a documentacao HTML em `docs/blog-estruturas-de-conteudo.html` e as rotas locais:

```text
/local/blog-estruturas
/local/estruturas-conteudo
```

Porem, nao havia uma entrada dedicada no admin para consultar essa referencia no mesmo padrao visual da Central Tecnica.

Arquivos alterados:
- `app/Controllers/Admin/TechnicalCenterController.php`
- `app/Views/components/admin/sidebar.php`
- `config/routes.php`
- `docs/features/IMP-015.md`

Mudanca realizada:
- Adicionado o item `Estruturas de Posts` dentro de `Central Tecnica -> Base de Conhecimento`.
- Criada a rota admin `/admin/central-tecnica/base-conhecimento/estruturas-posts`.
- Criada uma secao planejada com cards para texto base, blocos editoriais, comparativos, reviews, guias, midias, restricoes e referencia completa.
- Adicionada uma area de modelos copiaveis para usar em outra IA, com prompt mestre e exemplos de noticia, review, guia, comparativo e afiliado futuro.
- O item usa a capability `docs`, preservando a regra atual da Central Tecnica.
- A rota local `/local/blog-estruturas` permanece como referencia completa, mas nao e mais o destino principal do menu.

Impacto em producao:
Baixo. A mudanca altera apenas navegacao tecnica do admin e fica condicionada a capability `docs`.

Afeta rotas criticas:
Nao.

Mudanca de schema:
Nao.

Mudanca de dados:
Nao.

Dependencias:
- Rota local `/local/blog-estruturas` ja existente.
- Arquivo `docs/blog-estruturas-de-conteudo.html` ja existente.

Risco:
Baixo. O maior risco seria exibir o item em ambiente sem documentacao tecnica, mitigado pela capability `docs`, que hoje esta habilitada apenas no ambiente local.

Validacao:
- `php -l app/Controllers/Admin/TechnicalCenterController.php`
- `php -l app/Views/admin/technical-center/knowledge-section.php`
- `php -l app/Views/components/admin/sidebar.php`
- `php -l config/routes.php`
- `git diff --check`
- Conferir que o menu exibe `Estruturas de Posts` dentro da Base de Conhecimento no ambiente local.
- Conferir que `/admin/central-tecnica/base-conhecimento/estruturas-posts` responde pelo fluxo autenticado do admin.
- Conferir que `/local/blog-estruturas` continua respondendo como referencia completa.
