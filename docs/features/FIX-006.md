ID: FIX-006
Tipo: Correcao
Nome: Ajuste do link Blog no menu principal

Objetivo:
Corrigir o link do item Blog no menu principal para apontar corretamente para a secao Blog da Home quando essa secao estiver visivel na pagina inicial.

Contexto:
Foi identificado que o menu principal podia montar a ancora do Blog de forma inconsistente, usando `#blog` diretamente junto da URL base. Em alguns ambientes, especialmente stage/producao, isso fazia a navegacao cair na pagina ou trecho incorreto em vez de apontar de forma clara para a secao Blog da Home.

O comportamento desejado e:
- Menu principal: apontar para `/#blog` quando a secao Blog estiver visivel na Home.
- Rodape: manter a navegacao para a pagina `/blog`.

Arquivos alterados:
- app/Support/Helpers.php
- app/Services/Site/HomeService.php

Mudanca realizada:
- O helper de secoes passou a montar links de ancora com barra antes da ancora.
- Os links do Blog usados pela Home passaram de `#blog` para `/#blog`.
- A regra continua condicional: se a secao Blog nao estiver visivel na Home, o link segue apontando para `/blog`.

Banco de dados:
- Mudanca de schema: nao
- Mudanca de dados: nao
- Script necessario: nao

Impacto em producao:
Baixo. A mudanca afeta apenas a montagem de URLs do Blog no menu/links da Home.

Risco:
Baixo. O principal risco seria alterar tambem o rodape por engano, mas a regra documentada mantem o rodape apontando para `/blog`.

Validacao:
- Link do Blog no menu principal validado em stage.
- Ajuste aplicado em producao apos validacao da stage.
- Producao confirmou link do menu principal como `https://estrategianerd.com.br/#blog`.

Status:
- Local: ajustado
- Stage: aplicado e validado
- Producao: aplicado e validado

Observacoes:
- Esta correcao nao altera rotinas de backup, deploy, testes automatizados, Search Console, Dropbox ou content sync.
- Esta correcao nao altera o comportamento do rodape.
