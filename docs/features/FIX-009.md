ID: FIX-009
Tipo: Correcao (layout e admin)
Nome: Correcao de proporcao e espacamento de imagens no blog e resolucao de assets no admin

## Objetivo

1. Eliminar o espacamento vertical excessivo (tarjas/vazio) acima e abaixo de imagens especiais em blocos de conteudo dos artigos do blog.
2. Corrigir as imagens quebradas (404) na tela de edicao de posts no painel administrativo (`/admin/editar-post`).
3. Realizar o deploy seguro com backup imutavel e validacao remota para o ambiente de Stage.

## Contexto e Causa Raiz

1. **Espacamento vertical no blog**:
   - Elementos com as classes `.content-block-image-special figure img` e `.article-figure.content-media-special img` possuiam regras rigidas de `height: 30rem; max-height: 30rem; object-fit: contain; padding: 1rem;` tanto no arquivo `public/assets/css/site.css` quanto no metodo de normalizacao editorial `PostService::normalizeEditorialFigures()`.
   - Adicionalmente, os containers de figura possuiam `min-height: 30rem;`.
   - Em telas menores (mobile/tablet) ou imagens com proporcao 16:9 (como o mapa de Santuario no post de Diablo), o `contain` somado ao `height: 30rem` (480px) forcava a imagem a ficar restrita no centro com um gigantesco espaco vazio escuro acima e abaixo.

2. **Imagens quebradas no admin (`/admin/editar-post`)**:
   - O editor de posts carregava imagens gravadas com caminhos relativos (ex.: `uploads/posts/...`).
   - Quando renderizado sob `/admin/editar-post`, o navegador resolvia o caminho relativo a partir do path atual, requisitando `/admin/uploads/...`.
   - O servidor web (Apache) nao possuia rota de rewrite mapeando `/admin/uploads/*` ou `/admin/assets/*` para a pasta fisica `public/uploads/*`, gerando HTTP 404.

## Solucoes Implementadas

1. **Ajuste CSS (`public/assets/css/site.css`)**:
   - `height: 30rem; max-height: 30rem; object-fit: contain; padding: 1rem;` alterado para `display: block; height: auto; max-height: 36rem; object-fit: cover; padding: 0; margin: 0 auto; width: 100%;`.
   - Regra de container `min-height: 30rem;` alterada para `min-height: 0;`.

2. **Ajuste de Normalizacao de Estilos (`app/Services/Site/PostService.php`)**:
   - No metodo `normalizeEditorialFigures()`, as regras embutidas inline em blocos especiais foram alteradas de `height: 30rem`, `max-height: 30rem`, `object-fit: contain`, `padding: 1rem` para `height: auto`, `max-height: 36rem`, `object-fit: cover`, `padding: 0`.

3. **Ajuste no Roteador Apache (`.htaccess`)**:
   - Adicionada regra explicita: `RewriteRule ^admin/(assets|uploads)/(.*)$ public/$1/$2 [L]`.
   - Validado retorno HTTP 200 para requisicoes em `/admin/uploads/...`.

4. **Script de Deploy e Backup Imutavel (`scripts/deploy-stage-blog-image-fix.php`)**:
   - Suporta `--backup`, `--deploy`, `--verify` e `--rollback` com alvo restrito a `--target=stage`.
   - Realizou backup previo dos arquivos remotos antes de qualquer escrita em `storage/deploy-stage-blog-image-fix/stage/before/`.
   - Calculou e comparou hashes SHA-256 local vs remoto.
   - Validou via HTTP a presenca das regras e HTTP 200 no endpoint de Stage (`https://estrategianerd.com.br/stage/assets/css/site.css` e `https://estrategianerd.com.br/stage/post/o-mundo-de-diablo-entenda-santuario-ceu-e-inferno`).
