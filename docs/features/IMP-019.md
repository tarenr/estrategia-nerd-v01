# IMP-019 - Alertas informativos na Hostinger API

Tipo: Melhoria
Status: Implementado
Data: 2026-08-02

## Contexto

A tela Hostinger API exibia cada assinatura com auto-renovacao inativa como alerta `warning`. A informacao e util para controle financeiro e operacional, mas nao deve ser tratada como alerta critico quando a assinatura esta ativa e com vencimento futuro.

## Escopo

- Agrupar assinaturas com auto-renovacao inativa em um unico alerta.
- Deduplicar nomes repetidos por contagem.
- Classificar auto-renovacao inativa como `info`.
- Manter alertas de dominio, DNS, hospedagem e forwarding com a classificacao existente.

## Arquivos alterados

- `app/Services/Site/HostingerApiService.php`
- `docs/features/IMP-019.md`

## UX

A area de alertas passa a separar melhor informacao operacional de problemas reais. Auto-renovacao inativa continua visivel, mas sem competir visualmente com alertas que exigem atencao tecnica imediata.

- `C:\xampp\php\php.exe -l app\Services\Site\HostingerApiService.php`
- Leitura sanitizada da API Hostinger em CLI, sem expor token.
- `git diff --check`

## Observacoes

Sem mudanca de schema e sem mudanca em dados. A tela continua somente leitura.
