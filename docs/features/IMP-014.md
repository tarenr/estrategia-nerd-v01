ID: IMP-014
Tipo: Melhoria
Nome: Plano de melhoria editorial, SEO, conversao e estrutura de afiliados

Objetivo:
Documentar o plano de evolucao do site publico do Estrategia Nerd para fortalecer a Home, melhorar SEO tecnico/editorial, aumentar autoridade de marca, melhorar conversao para newsletter e preparar a base para monetizacao futura com afiliados.

Contexto:
Foi analisado um prompt de melhoria ampla para o site estrategianerd.com.br, com foco em Home, posts, newsletter, SEO, performance, afiliados e rodape. A analise foi comparada com o codigo real do projeto e com a documentacao de governanca.

O projeto ja possui varias bases implementadas:
- Home com hero, posts, blocos editoriais e newsletter.
- SEO centralizado no layout publico.
- Open Graph e Twitter Cards.
- sitemap.xml e robots.txt.
- Schema.org para Organization, WebSite, WebPage, CollectionPage e Article.
- Paginas de post com tempo de leitura, sumario automatico, comentarios, likes e posts relacionados.
- Central Nerd com estrutura inicial para links, ofertas e produtos.
- Newsletter com formulario de nome/e-mail e envio via AJAX.

O plano abaixo evita recriar motores existentes e organiza a evolucao em fases pequenas.

Escopo planejado:

1. Home e posicionamento editorial
- Reforcar o texto do hero para deixar claro o diferencial do portal.
- Criar secao "Por onde comecar?".
- Destacar caminhos editoriais como Hardware, Games, Dicas, Reviews e Setup do Dev Nerd.
- Melhorar CTAs principais:
  - Ver reviews
  - Montar meu setup
  - Receber ofertas e guias
- Reforcar o bloco de autoridade "Quem esta por tras do Estrategia Nerd".

2. Newsletter
- Melhorar titulo, texto e botao da newsletter.
- Manter campos Nome e E-mail.
- Sugerir nova copy:
  - Titulo: Receba o melhor do Estrategia Nerd sem ruido
  - Texto: Reviews, comparativos, setups, ofertas uteis e guias para decidir melhor antes de comprar ou montar seu proximo upgrade.
  - Botao: Entrar para a lista nerd

3. Paginas de posts
- Exibir autor de forma clara.
- Adicionar breadcrumb visual.
- Adicionar schema BreadcrumbList.
- Inserir CTA de newsletter no meio e no final do artigo.
- Melhorar o bloco de posts relacionados, podendo usar o texto "Voce tambem pode gostar".
- Preservar sumario automatico, comentarios, likes e estrutura atual.

4. Categoria Setup do Dev Nerd
- Criar categoria "Setup do Dev Nerd".
- Descricao sugerida:
  Guias, ideias e escolhas inteligentes para montar um setup gamer, produtivo e preparado para programacao, estudo e criacao de conteudo.
- A criacao deve ser feita como mudanca de conteudo/dados, com cuidado para manter paridade entre ambientes.

5. Estrutura para afiliados
- Reaproveitar a base existente da Central Nerd e Links.
- Criar componente editorial de card de produto.
- Criar componente editorial de tabela comparativa.
- Campos previstos:
  - Nome do produto
  - Imagem
  - Pros
  - Contras
  - Melhor para
  - Botao "Ver preco"
  - Aviso discreto de afiliado
- Nao misturar esta etapa com deploy editorial ou sincronizacao de dados sem autorizacao.

6. SEO tecnico
- Revisar hierarquia H1, H2 e H3.
- Garantir apenas um H1 por pagina.
- Manter meta tags centralizadas no layout publico.
- Nao duplicar Open Graph, Twitter Cards, canonical ou schemas existentes.
- Adicionar BreadcrumbList onde fizer sentido.
- Revisar alt text de imagens principais.

7. Performance
- Medir antes de otimizar.
- Validar impacto de fontes externas, Tailwind CDN, JS e imagens.
- Manter lazy loading em imagens.
- Otimizar assets somente apos medicao real.

Impacto em producao:
Potencialmente medio, pois envolve paginas publicas, SEO, navegacao e componentes editoriais. Deve seguir o fluxo:
Local -> Stage -> Validacao -> Pacote da Stage -> Producao.

Mudanca de schema:
Nao prevista inicialmente.

Mudanca de dados:
Prevista apenas para a categoria "Setup do Dev Nerd", se criada via banco/admin/conteudo.

Dependencias:
- Validacao visual em mobile, tablet e desktop.
- Validacao de SEO tecnico.
- Validacao de rotas publicas.
- Validacao de sitemap/robots.
- Validacao de newsletter.

Riscos:
- Quebrar identidade visual atual se a Home for redesenhada em excesso.
- Duplicar SEO ja centralizado no layout.
- Introduzir schema redundante ou inconsistente.
- Misturar conteudo editorial com deploy tecnico.
- Criar categoria somente local e esquecer stage/producao.
- Alterar textos com acentuacao em arquivos sensiveis a encoding.
- Otimizar performance sem medicao previa e causar regressao visual.

Ordem recomendada:
1. Home e newsletter.
2. Posts e breadcrumb.
3. Schema BreadcrumbList e revisao de hierarquia.
4. Categoria Setup do Dev Nerd.
5. Componentes de afiliados.
6. Performance com medicao antes/depois.

- Validacao visual responsiva.
- Validacao de newsletter.

- Validacao de que nao houve alteracao em rotinas operacionais criticas.
