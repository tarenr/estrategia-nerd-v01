# Estrategia Nerd (PHP puro)

## Rodar local
Acesse:
- https://localhost/estrategia-nerd/

## Preflight rapido
Antes de alterar ou publicar, rode:

```bash
php scripts/preflight-check.php
```

## Pastas
- public/ = único diretório público
- app/ = código
- config/ = configurações
- views/ = templates
- database/ = SQL
- scripts/ = scripts CLI
- storage/ = logs
